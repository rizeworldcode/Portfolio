# Rizeworld — Graphic Design Portfolio

A dynamic, high-performance visual portfolio showcasing 200+ graphic design works across diverse industries (Healthcare, Education, Food & Hospitality, Real Estate, Gemstones, Election Campaigns, Packaging & Branding).

## Features
- **Hero Adoo Section**: Majestic typography with dynamic animated background cyclical preview.
- **Interactive 3D Tilt Glossy Cards**: Framer-inspired mouse-tracking tilt effect with specular reflection and gloss ring.
- **Adaptive Balanced Gallery**: Flex-column balanced gallery layout that shows posters in their natural 100% full aspect ratios (0% cropping).
- **Full-Screen Lightbox**: High-resolution image preview with arrow key navigation, mobile touch swipe, and escape controls.
- **Liquid Glass Footer**: Frosted glass shell with smooth metallic rim gradients, responsive newsletter connect, and social links.
- **100% Responsive Design**: Fluid layouts optimized for Desktop, Tablet, Mobile, and foldable screens.

## Tech Stack
- **Framework**: React + Vite
- **Styling**: Vanilla CSS & Glassmorphism Design Tokens
- **Animations**: Framer Motion
- **Icons**: Custom SVG

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
